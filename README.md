# Training Center Management System

A full-stack web platform designed for educational and IT training institutes to manage student enrollments, course catalogs, fee payments, and automated certificate generation.

## Key Features

* **Student Enrollment & Tracking:** Manage student profiles, contact details, and course registration history.
* **Course & Fee Management:** Configure course offerings, installment schedules, and track payment status.
* **Certificate Generation:** Print-formatted and automated certificate issuance upon course completion.
* **Dashboard Analytics:** Overview of active students, upcoming class schedules, and tuition fee collections.

## Tech Stack

* **Backend:** Java 17, Spring Boot, Spring Security, RESTful APIs, Spring Data JPA
* **Frontend:** React, TypeScript, Tailwind CSS
* **Database:** MySQL
* **Build Tool:** Maven / Vite

## 💻 Getting Started

### Prerequisites

* JDK 21
* MySQL 8.0+

### Setup Instructions
   ```bash
   git clone [https://github.com/thantaungsatt/Training-Center-Management-System-Web.git](https://github.com/thantaungsatt/Training-Center-Management-System-Web.git)
   cd training-center-management
   Configure MySQL connection in src/main/resources/application.properties and run: mvn clean spring-boot:run
